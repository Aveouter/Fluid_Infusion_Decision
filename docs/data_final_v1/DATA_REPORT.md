137,830条临床观测/候选保留来源和资格，小时聚合117,547行；不合格候选不作为数值输入。字典覆盖27张主要/来源表、394个字段定义和47种临床字段/单位/限定符/提取方法组合。普通尿量和残余尿分别保留，未确认单位的收集量不称mL/h。
