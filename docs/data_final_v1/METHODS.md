# 数据来源、提取规则与逐层追溯

本说明只讨论数据，提取工具不导入模型、训练器、损失或实验预测。工具使用冻结的数据解析依赖；原模块名、原SHA256、移入独立命名空间后的SHA256及变更说明见tools/final_data/vendor_manifest.json。

## 1. 原始来源与重放层级

|来源|用于什么|如何定位|
|---|---|---|
|449份患者原CSV|入量、出量、护理原文、体征与文本检验|患者来源键、FORM_ID、FORM_TIME、INNER_SEQ、组合项目名称及CSV逻辑记录号|
|医生速度原ZIP|按小时、按成分记录的设备设置变化|ZIP成员名、数据记录号、晶体/胶体/水速度列；空白不生成0速事件|
|基线Excel|入院时间、人口学及烧伤基线|门诊编号匹配行；字典保留全部来源Excel行|
|历史药名分类表|分类参考与保守文字修正|原药名/途径、规范化键、实际匹配规则；参考表不视为绝对真值|
|既有clock_corrected_v3提取账|已作出的回顾性量、批次、完成与负量处置|原事件、案例、批次和anchor ID；冻结原recipe与参数|

Final构建分两级：先将既有提取账、边界和必要来源材料整理成独立build_inputs并校验指纹；随后重新读取449份原始患者CSV、医生原表和基线，重提原始入量组合，按相同规则提取416人的临床观测、时钟/设置和因果状态，生成统一表。

本构建器可从冻结build_inputs加原始文件重现Final装配和新增原始观测提取，不声称仅凭这一个命令重新进行了历次全部临床语境裁决。旧回顾性处置账是显式版本化输入，原生成代码、规则和处置证据随本地包保存；其已知推断性质不会因进入Final而消失。

## 2. 原记录组合、编码和索引

原CSV按登记的编码读取（来源以GB18030为主，保留逐文件编码与SHA256），不以错误替换字符悄悄解码。入量名称、量、途径、实用/备用单位、备用量及分类必须来自相同FORM_TIME+FORM_ID+INNER_SEQ组合。相同字段多个不等值保留冲突，不从另一记录补一个看似合理的数。数值表示不同但数学相同的数量可判为等值。

小时主表和统一设置参考覆盖伤后72小时；原始来源/护理事件账可保留更长上下文与晚记录证据用于追溯。它们不是不加筛选的预测矩阵，仍须遵守时间窗口和双时钟可用规则。

本次重新组合入量时校验完整原文件，Final的raw_intake_events仅保留伤后[0,72)的结构化入量组合，较晚随访不重复塞进Final；完整原文件仍在raw并由指纹定位。既有回顾账额外的明确原句来源与结构化入量分开，不伪装成结构化原行。

保留NUMBER_VALUE和STRING_VALUE原集合到fields_raw_json。原提取source_record_number(s)为不含表头、从1开始的数据序号；新观测source_csv_record为含表头的逻辑记录号，首条数据为2。CSV字段可能包含换行，因此这不是文本编辑器显示的物理行号。

## 3. 患者、伤时、入院和结束边界

伤时沿用有来源索引的injury_time_local，并记录该索引的指纹。分析窗口固定伤后[0,72)小时。基线表“入院时间”为权威来源；匹配多行时使用非空最早值，缺失者排除，不采用护理首条记录代替。

333/83历史分组取自416人已有边界/分组提取记录；33名排除患者的旧分组未从该记录取得，因此该字段保留未知，不将未知写成“开发患者”。

完整小时需同时满足h>=admission_hour且h+1<=observation_end_lower_hour。日期级“今日出院”只提供当天区间，不猜精确时分；明确离院/死亡原句可提供具体时刻。观察结束还受原来源最后记录与72小时右截断限制，source_censored_or_72h不能称确认出院。部分入院/结束小时保留参考与边界元数据，但不作为完整小时监督。

## 4. 时钟与可用时间

源FORM_TIME末尾Z按已确定的本地墙钟语义保留本地时分，去掉时区标记，不再加8小时；原字符串仍保存。所有相对小时均为本地时间减伤时，再除3600。

护理原句中的明确事件时刻可定位小时内变化。原解析已防止SO2:100%等数值被错误识别为02:10。医生表“时间”1到72对应伤后小时起点0到71，统一标hour_estimate，而非真实整点操作证据。只有同成分、同速度、同小时、明确“调/改/开始”且唯一时刻的护理证据才可校正该医生事件时间；不整体移动标签。

同一事件同时保留发生时刻和原记录业务可见时刻。因果库存要求二者都严格早于预测起点。临床数值以记录小时汇总，available_at_hour=h+1，预测起点只可消费结束时刻<=起点的bin。该业务代理未经真实在线录入日志验证，也不等同采血/测量时刻。

## 5. 药名、分类、单位和途径

原药名永不覆盖，另列修正名、原分类、修正方法与问题。规范化采用NFKC、空白/标记处理及受限剂量后缀处理。顺序包括名称+途径精确参考、规范化参考、登记途径别名、明确复核药族规则、名称唯一参考以及受限错字候选。模糊匹配要求名称至少8字符、相似度>=0.94，并保持数字、浓度和关键药族锚点一致；多候选第一与第二差需>=0.03。不借其他包装的参考名改原包装容量。

数量显式mL/毫升/cc按1倍，L/升按1000倍；有相冲突的单位不静默择一。瓶/袋数只可乘原名称中唯一明确的包装mL容量，记录count_times_explicit_package_volume，不说成直接体积记录。备用单位只有同组且规则允许时补充。负值进入负量处置账，不直接成为负小时输入量。

静脉注射、静推、静注等药物注射不算补液。口服/鼻饲/胃肠途径单列液体。三类静脉量分别为晶体、胶体、水；这些是原项目业务类别，不能据名称推断真实独立通道或混合配比。

主补液与明确药物载液/肾替代辅助液分开。预测输入的用途过滤仅允许原始用途、同FORM_ID同记录钟的护理证据；药物载液需明确混配、泵入及唯一同族同量绑定。冲管与载液混合而无法区分时保持不确定，不按“泵入”“三升袋”字样一刀切。回顾性量表的既有用途判定另保留，不能用后来完成/停用解释过滤先前因果来源。

## 6. 整瓶量、重复、负量、退回与批次

登记的整瓶/整次量表示放入待输装置或待输库存的来源量，不表示该小时已经进入患者。后续同成分量排队进入FIFO，旧瓶耗尽后使用下一瓶；三成分独立核算。同袋关系只作证据，不自己按瓶量分配成分速度。

原回顾性重建保留跨表单近重复推断：相同规范化血液名称、量和子项序号、相距<=120秒且没有明确额外一袋证据时可形成候选。canonical_event_id保留来源别名；这是中等证据推断，不宣称重复内容必然是同一物理事件。

负量按语境分为短时间正负续记/抵消、尚余继续输的库存检查点、未用退回/取消，以及不能匹配库存的账务更正。未用退回优先关联兼容、未完的来源批次/队列尾部，取消量不得超过可取消库存，超出部分单列。每批满足original_volume_ml-cancelled_ml=net_ml，net_ml=modeled_consumed_ml+remaining_at_episode_end_ml。该净量仅供回顾核算；因果容量仍使用起点前原始可见加液量。

## 7. 缺量与文本恢复

既有量参考按实际原句、同患者同药物记录、名称括号外明确临床量、原数量栏缺单位/错单位语境等逐条恢复，volume_resolution、volume_confidence及决策ID完整保留。个别血液单位换算和白蛋白典型量含项目/患者惯例，不能标为原始明确mL。

新因果来源更保守：仅接受原始显式体积，或同表单、同记录钟、唯一同族记录、含实际“予/给予/开始/输入/输注”的明确mL原句；数值冲突、计划、剩余、累计、昨日、停止等不作新加液。仅在药名里看到包装/体积不自动变成已知新库存。未量化线索保存为unknown_quantity_cue，不补固定瓶量，不把线索数解释为真实缺瓶数。

## 8. 设备设置与分段输入量

医生人工表为主要来源，空白表示没有新记录；已知设置在变化点之间延续。未知初始设置先查明确护理原句，仍无依据则保留NA，不能因“无记录”填写设备0速。医生已经有该成分设置时，后续护理数值冲突不静默覆盖；明确类别暂停可给0，恢复要求已有正速度，不借全体典型速度。

回顾性设置曲线保留起点设置、小时结束前左极限和设置×时长积分。事件恰在h+1归下一小时。三者不可互相替代，也不能用完成量倍率改写医生设置。

实际输入量普通分支按有限库存分段积分，库存归零时精确截断并切下一批，将跨小时/跨批输入拆开。旧完成端点分支先按兼容批次形成累计量约束，再按原设置时长权重拟合倍率；若不能用该权重分配而来源时序仍允许，则用标记的均匀时间估计。求解器保持不早于来源释放、FIFO和总量守恒。倍率scale和estimated_actual_rate_ml_h属于回顾性过程估计，不是设备设置，也不能作为预测输入。

设置缺失时，旧量重建可能依次使用患者同成分已记录速度中位数、患者库存周转估计、年龄组/全体同成分医生非零速度中位数。项目中3000mL/h为推断过程的合理性守卫，不是临床治疗上限。涉及跨患者速度先验的患者在Final中单独标记并保守排除主量参考资格；原量不删除。所有后续模型须使用相同分母，不把跨版本分母变化说成模型收益。

手术汇总量、前院总量和不确定手术转换不能解释成明确新瓶或床旁停输。保留原估计区间、来源ID和数量，将无精确流量的分配区间标不适合精确量—速联合监督。期末截断余量不凭空丢弃。

## 9. 冲管和口服液体

明确冲管量、时长、起止线索保留在原句账中；缺记部分不补统一固定量或时长。葡萄糖冲管可以改变实际液体类别，不能仅因设备设置沿用而把它记为胶体。缺记冲管影响未纳入的标记保留。

口服和鼻饲只统计液体部分。直接液体比例1、固体比例0；旧语境估计包括粥0.8、蒸蛋/蛋羹0.5、米糊0.7、液体+固体0.5、粥+固体0.6、粥+液体0.9。药物配明确水按液体，单纯片/胶囊不臆造饮水。记录缺量可先用患者同名中位数，再用全体同名中位数，否则未知；oral_quantity_method逐条指出来源。这些比例是项目近似，不是测得的营养水含量，口服量也不并入三类静脉输入量。

## 10. 基线、结构化体征、尿量和检验文本

基线按患者匹配行取唯一非空数值；冲突不取均值。年龄由伤时减出生日期除365.25天，范围0–120岁；男/女分别1/0。身高<3时按米转厘米，体重>1000时按克转千克；固定守卫范围为身高40–250、体重2–250、BMI5–80、各烧伤面积0–100、吸入性损伤0–1，超出为未知且保留原表可核对。基线值可用时点用入院业务代理，不保证每项实际录入都在此时完成。

结构化前九项按规范化节点/父节点/项目名定位NUMBER_VALUE，同小时中位数。沿用固定源尺度守卫：体温25–45、心率/脉搏15–300、呼吸3–100、收缩压30–300、舒张压10–220、CVP−10–50、SpO2 20–100、血糖1–60。记录尺度不明确时unit注明recorded_*_scale，不把范围检查当成源单位证明。CVP只在NUMBER_VALUE空白且STRING_VALUE为范围内纯标量时恢复；不解析未知单位或范围串。超守卫的已记录候选保留为不合格观测，不改成0。

尿相关出量必须同FORM_ID+FORM_TIME+INNER_SEQ绑定名称与量，唯一数值并沿用0–5000守卫。没有明确单位的数值使用urine_recorded_amount_unspecified_unit，不再因旧字段名含ml就声称有单位证据；不由记录间隔推断收集时段或除成尿流率。残余尿独立命名，不并作新产生尿量。同钟跨表单相同数值不能仅凭相同内容自动删去。

文本保留明确单位的乳酸、BE、HCO3、pH、PCO2/PO2、血红蛋白、肌酐、心指数、GEDI、ELWI等；血红蛋白明确g/dL可乘10转g/L。PCO2/PO2不因旧pa前缀声称已验证动脉标本。PCCI字面mln→min、GEDI明确单位前多余冒号属于受限拼写修复，原串仍在。原句无单位/不确定上下文另存候选，不猜单位。

明确单位的血糖、Na、K、Ca、Hct、tHb和部分乳酸/Hct上下界另外提取，条件句、目标、他人、历史引用、治疗浓度等不作当前精确值。三位及以上整数K保留原值和隔离原因，不猜小数点，也不改成钠。上下界与精确值分别分组；同字段同小时的规范单位原值优先于拼写修复。

相同NFKC长原文（>=80字符）按记录时钟只保留首个进入数值聚合，后续仍保留拒绝账；短重复不强行删除。小时聚合按患者、小时、字段、单位、限定符分组，普通数值取中位数，尿收集登记量仅在相同明确/未知单位组内求和，不称该小时实际产尿。原观测ID全部连回逐条记录。clinical_fields.csv列出实际字段、单位、限定符和提取方法组合。

## 11. NA、0、冲突和监督资格

入院前、结束后或部分边界小时主分析量为NA。完整住院小时确无登记输入为0；有未定量来源、未知设置或临床缺测仍保持未知，不能把“住院内无输入为0”推广成所有缺失填0。原旧重建值另外保留用于复核，不覆盖边界外原证据。

量与设备设置两条证据不一致时保留两者。精确联合资格排除：完成区间总量超出宽松设置时钟上包络的区间；小时分配超出上包络并追到原端点区间的情况；低于来源条件库存/设置过程估计的小时及其关联分配区间；手术/前院区间分配和未定手术转换；未量化来源及设置未知。0.01mL仅是算术比较容差，不是临床偏差容许线；不按10mL或模型误差筛选。条件库存下界差异不证明临床源记录必错，可能来自缺记暂停、退回、用途或重建分配。

quantity_reference_eligible保留完整边界内有限量且排除既有跨患者速度先验依赖；setting_reference_eligible要求完整边界及结束前设置已知；exact_joint_eligible另要求整个设置曲线已知且无上述不确定性。原量、原区间总量、原设置及资格/原因分列，后续模型必须共用同一版本与资格。

## 12. 因果历史状态和重放

状态仅接受已可见addition与setting，不支持回顾完成事件。已知速度下按有限库存消耗；库存可能为正且速度未知时下界可降0，上界保持，保存unknown_flow_exposure_hours。上下界相同才给remaining_point_ml，中点另标估计。记录时刻晚于起点，即使事件时间声称早于起点，也不能进入该起点。

```powershell
python -m tools.final_data.build prepare --repository . --out data/organization/新的输入快照
python -m tools.final_data.build build --inputs 数据输入快照 --raw-root data/raw --out data/datasets/新的候选包
python -m tools.final_data.release curate --package 新的候选包
python -m tools.final_data.validate --package 新的候选包 --raw-root data/raw
python -m tools.final_data.dictionary --package 新的候选包 --public docs/data_final_v1
python -m pytest tests/test_final_data_package.py -q
```

首次prepare只读提取层来源和旧边界/历史分组元数据；后续重放build不再依赖旧实验目录。输出目录必须是新版本，不覆盖已有包。manifest记录输入、代码与运行依赖，最终文件索引覆盖实际输出；训练、插补、标准化、窗口、模型配置和成绩均不属于数据发布过程。

## 13. 核验与结果解释

独立核验包括449原文件SHA256、医生原ZIP逐条数值、416×72×3唯一网格、边界NA、量非负、批次原量/取消/净量及消耗/余量守恒、按区间重叠独立重放小时量、临床单位/限定符分组、因果状态边界和未来完成事件扰动。公开仅发布聚合结果，不暴露病例或小类个例。

这些核验验证计算、来源与规则一致性。独立医生盲法复核未完成；手术语义、缺记过程、源单位和收集周期的证据不足按字段/区间保留，不因Final版本固定而被宣布已临床确认。后续纠错必须另发版本，保存旧结果并记录分母与规则变化。
