# 新时序多任务补液模型（NM-v1）实验结果

日期：2026-10-15。对应验收规范《新时序多任务补液模型验收规范》Gate A–G。

本轮交付一个**独立的新时序多任务模型**：共享因果编码器 + 两条显式桥接的任务塔 + 回归、活动、事件、方向、幅度五组头，输入量与设置速度各自独立输出，动作输出由事件头门控。它不是旧模型的组合，也不是阈值再调优；阈值只在开发患者的内层 OOF 上选一次。

## 1. 任务与输出

伤后 1–71 小时每小时一个预测原点，预测 `[h, h+1)`：

| 输出 | 口径 |
| --- | --- |
| 输入量 | 三类液体各一个回归输出（mL） |
| 设备设置速度 | 三类各一个点预测（mL/h） |
| 平均输入速度 | 由输入量与 1 小时派生，**不作为训练标签**，也不用于把设置速度换算成输入量 |
| 液体活动概率 | 输入量与设置速度各自的活动头 |
| 设置动作 | 事件概率、方向类别、条件幅度；解码为「上一小时设置 ± 幅度」 |
| 停止 | 本标签集不可估计，如实报 NA，不制造负样本 |

解码关系在代码里显式写死：`动作 = 上一小时设置 + 方向符号 × 幅度`，仅当事件头越过该液体的阈值时发生；锚未知时回落到点预测。输入量与设置速度的点预测互相独立。

## 2. 数据与因果（Gate A）

| 检查 | 结果 |
| --- | --- |
| 特征因果性 | 随机化每个原点及以后的全部小时与两个标签数组后，窗口、锚、静态块与摘要逐位不变 |
| 患者隔离 | 449 名患者分 5 折、内层 3 折；组从不跨折；留出患者从不进入内折 |
| 缺失处理 | 观测零保留为真值；被掩码的行从每个损失项剔除，不用 0 填充 |
| 库存守恒 | 累计输入 ≤ 累计入库、库存与输出速率非负，全队列逐一检查通过 |
| 可用时间 | 基线特征按其可用小时开放，早于该小时的静态块为缺失而不是零 |

本轮**不构造任何交叉患者的标签依赖**：输入只读 k<h 的记录与因果库存代理，参考标签的回顾性来源在报告与本轮定位中如实标注。

## 3. 模型与训练（Gate B）

**结构**：缺失感知的序列投影（数值 + 缺失指示）→ 因果膨胀卷积堆（dilation 1/2/4）→ 静态 FiLM 调制 → 掩码注意力池化 → 共享干路 → 两条任务塔，塔间有显式门控桥 → 五组头。掩码统计分支给出每通道的末次值、均值、标准差、首末趋势、观测次数与观测年龄。参数规模 10.8 万。

**损失**：输入量 L1/50、设置点 L1/50、两个活动头 BCE、事件头 BCE、方向头交叉熵、幅度头 L1/100，全部按患者等权加权、按掩码计。任务权重预注册，未按结果调整。

**训练**：AdamW，lr 2e-3 余弦退火至 1e-4，批 512，60 轮，三个固定种子 20261015/16/17，梯度范数裁剪 5。

## 4. 数据增强（Gate C）

三种与临床时序语义相容、且只作用于**输入观测**的增强：

| 策略 | 语义 |
| --- | --- |
| dropout | 把一段连续的生理观测标为未记录，对应记录间断 |
| noise | 对已观测的生理值加测量误差 |
| truncation | 把最早的一段观测标为未记录，对应可用历史更短 |

三者都不改动输液、库存与小时通道，不改变标签与掩码，不伪造数值。主模型**不使用增强**；无增强、单项、组合在相同结构、划分、真实验证患者与预算下对照。结果见第 7 节。

## 5. 评估口径

- 输入量：患者等权 MAE（三类液体平均），并报 RMSE、偏差、正输入时段误差、p95 与超过 50 mL 的错误占比。
- 设置速度：总体 MAE，另报保持小时、变化小时、上调小时、下调小时。
- 动作：**同小时、同方向、同动作类别**的严格 F1（三类液体宏平均），另报各类真实支持数、预测数、TP/FP/FN、精确率与召回率，上调召回与上调误报并列。
- 统计：患者整群重采样 2,000 次、seed 20261015 的配对区间；训练随机性与患者抽样不确定性分开报告；不做全局优越性主张。

阈值选择：每个液体一个事件阈值，在开发患者的内层 OOF 上最大化严格 F1，并列取更高阈值；两个点输出另配内层 OOF 拟合的护栏（α=0 退回锚、α=1 且 τ=0 等于模型）。历史留出在冻结之后才评估，且它此前已被查看，只作标记清楚的回顾性评估。

**指数一致性交叉验证**：同一套评估代码作用在 V6 的已保存外折预测上，逐位复现报告数字——输入量 30.1645、设置 11.8353、事件 F1 0.1343、严格动作 F1 0.1212；历史最强混合 30.2638、因果库存锚 36.1647、最强提升树 33.1405。因此本轮的对照与上一轮报告的分母、掩码与权重口径一致，不是另一把尺子。

## 6. 预设目标与达成情况

三项性能目标在训练前登记（`registered-protocol.json`），判定如下。**模型成功、专项改进成功与交付成功分别判定，不互相替代。**

| 目标 | 预设阈值 | 基线 | 新模型 | 判定 | 配对 95% 区间 |
| --- | --- | --- | --- | --- | --- |
| D1 输入量 MAE 相对最强基线降低 ≥3% | 3% | 30.2638 | 30.9351 | 未达成 | [0.259, 1.144] |
| D2 总体设置 MAE 不增加 | 不增加 | 10.7961 | 10.9659 | 未达成 | [0.088, 0.233] |
| D3 严格动作 F1 相对 V6 提升 ≥0.03 | +0.03 | 0.1212 | 0.1932 | 达成 | [0.056, 0.087] |

**D1（输入量）未达成。** 新模型开发集输入量 MAE 高于预定最强基线，且患者配对区间整体位于零以上——不是「没有证据」，而是**有证据表明更差**。最强的历史模型其实是上一轮的 V6（低于历史最强混合），新模型相对 V6 同样更差。唯一满足的 D1 附属要求是活动 Macro-F1 非退化。

**D2（设置速度）未达成。** 模型自身的设置点输出比持续性基线高 0.010 mL/h，配对区间不跨零（差异极小但方向明确为变差）。内层护栏在**每一折、每一液体**都选到 α=0，也就是「完全不采纳模型自己的设置步进，保持上一小时设置」；但那正是验收规范明文禁止的路径（「禁止通过减少全部变化预测获得低总体 MAE」），因此不作为达成证据记录，只作为两个输出相互冲突的证据。**结论：本模型的设置点回归头对 MAE 没有可用贡献。**

**D3（动态动作）达成。** 严格同小时、同方向、同动作类别 F1 从 V6 的 0.1212 升到 0.1932，配对区间下界远高于 +0.03 的目标；上调召回从 0.0128 升到 0.2308。这一项的改善与输入量、设置速度两项的退化同时发生，说明**收益集中在动作端点，而不是整体性能提升**。

**设置点端点对结构不敏感**：所有变体的设置 MAE 都落在 10.956（其中 `仅设置` 为 10.964），因为它们的内层护栏都选到 α=0，即退回上一小时设置。这再次说明该端点不由这些结构选择决定。

### 9.2 组合与混合探测：D1 的差距不是「组合没做好」

历史最强混合的单体模型各自只有约 32.4，靠逐头组合做到 30.26；本轮的**单体**模型（约 31.0）本就优于它的任一单体，但种子平均只有 30.94。因此差距看起来是组合效应。针对这一点做了两次探测，两次都否定了该解释：

| 探测 | 结果 | 说明 |
| --- | ---: | --- |
| 历史最强混合（对照） | 30.264 | 由 4 个异构单体 + 逐头选择 + 护栏组合而成 |
| 新模型（种子平均 + 护栏） | 30.935 | 本轮登记配置 |
| **新模型家族的内层 OOF 贪心集成** | **30.643** | 11 个变体、逐液体、按 `reports/nm_stack_probe.py`，**只用内层 OOF 拟合**，外折分数有效 |
| 0.3×新模型 + 0.7×历史混合 | 29.974 | 权重在同样本上选，乐观上界 |
| D1 目标 | 29.356 | 相对最强历史基线降低 3% |

**读法**：把本轮全部变体按内层 OOF 组合只回收 0.29 mL；逐行选择器（11 个成员 × 6 个 α × 7 个 τ = 462 组合/液体，同样只用内层 OOF）**更差**（34.39），即在这点样本量上过拟合。**D1 的 3% 目标在这条技术路线上不可达**——不是组合方式没选对，也不是单体不够好。分液体看差距均匀分布在三类液体（新模型对强混合：晶体 39.53 对 38.95、胶体 28.68 对 27.97、水 24.60 对 23.88），不是某一类液体拖累。

### 9.3 D1 的可达性上界：连 oracle 组合也够不到

把本项目现存的全部预测因子放在同一指数上——新模型、历史最强混合、上一轮 V6、最强提升树、因果库存锚——在**开发集本身**上拟合凸组合权重（即在评测数据上挑权重，最有利情形），得到该组合类在此指数上的最小值：

| 项 | 数值 |
| --- | ---: |
| 最优凸组合权重 | 新模型 0.31、V6 0.57、历史混合 0.12、提升树 0、库存锚 0 |
| **oracle 最小输入量 MAE** | **29.937** |
| D1 目标（强混合降 3%） | 29.356 |
| 距目标仍差 | 0.581 |
| **任何凸组合能否达到 D1** | **否** |

**这是可达性上界而不是结果**（权重用了评测数据本身，只能说明「做不到」）。它的含义很明确：**即使允许把历史模型直接当输入用**，现存预测因子的任何加权都达不到 D1 的 3% 边际。要拿到 D1，需要的是误差**不被这五个预测因子张成**的新预测器，而不是换一种组合方式。这解释了为什么本轮的结构改进、增强、种子、护栏、集成与选择器全都无法越过这条线。

**更宽的假设类同样失败**：凸组合只是一个受限类。把假设类扩到「五个模型预测 + 170 列窗口统计 + 锚」的**任意函数**——逐折诚实拟合的非线性 stack（HGB，L1，以最强单模型 V6 为基学残差）——只回收 **0.056**（30.165 → 30.108）。该假设类把每一种凸组合都作为特例包含在内，因此它比上界更接近「是否存在某个组合规则能达标」的答案。

| 组合方式 | 开发集输入量 MAE |
| --- | ---: |
| 最强单模型（V6） | 30.165 |
| + 非线性 stack（五预测 + 全特征，逐折诚实） | **30.108** |
| 凸组合 oracle（权重用评测数据本身，作弊上界） | 29.937 |
| D1 目标 | **29.356** |

D2 同理：模型自身设置点输出的最优解码由内层 OOF 选到「保持上一小时设置」，即该输出的误差里没有可被利用的信号；把它与历史设置模型混合才能更好，而那已经不属于新模型的贡献。

### 9.4 残差可学性检验：剩下的误差提不出来

上界只覆盖「给定预测因子的凸组合」。更一般的问题是：最优组合之后剩下的误差，能否从**同一批输入**里学出来？做法是逐折用其训练行拟合组合权重（诚实做法，不看外折），再在训练行上训练一个残差模型预测 `真值 − 组合预测`，特征用与主模型同源的窗口统计（170 列，CVP 一列整列为空已剔除）。

| 项 | 开发集输入量 MAE |
| --- | ---: |
| 逐折拟合权重的组合 | **29.948** |
| 组合 + 同输入残差模型 | 30.019 |
| D1 目标 | **29.356** |
| 残差模型的增益 | **−0.071（更差）** |

**读法**：专门为残差训练的模型不但没有改善，反而变差——残差主要表现为噪声而不是尚未提取的结构。这条证据比凸组合上界更宽：它允许一个全新的非线性学习器，且给它的是与主模型同源的输入。

**边界**：该检验覆盖的是**这套输入**（29 个记录通道 + 静态基线 + 因果锚）加**本轮使用的特征与模型类**，不构成对所有可能模型的不可达性证明。它说明的是：要继续缩小输入量误差，需要的是**新的可观测信息**（例如小时内的事件时序、或本项目没有的泵遥测），而不是在同一批输入上换模型。
