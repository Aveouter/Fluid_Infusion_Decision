# 不使用历史补液信息，下一小时输入量和速度是否可学

日期：2026-10-15。完成五折患者分组评估：335 名输入量参考有效患者、296 名设置参考有效患者，共 20,239 个预测窗口。

## 1. 问题与判断标准

本实验只检验历史记录中的下一小时输入量和文书设备设置是否具有跨患者可预测性，不检验最优补液处方。允许静态基线、伤后时间和过去 24 小时的生理/记录尿量；完全禁止历史补液字段、其缺失模式、库存、设置速度、加液间隔、上一小时标签、旧模型预测和护理补液原文。

“比常数好”说明有粗略可预测规律；“比静态/时间好”说明历史记录有增量；“生理数值比只保留记录模式好”才支持数值本身的独立增量。三者不能互相替代。未达到某比较不证明信息论意义不可学。

## 2. 实验实施和防泄漏

- 使用冻结 V4 独立参考、原有效掩码、相同五折患者划分；不改变已查看队列，也不再次查看历史留出。
- 输入量及设置分别是三个液体输出。设置速度与输入量不互相换算；一小时平均输入速度由预测输入量派生。
- 树模型直接回归绝对量，没有患者历史锚点。神经模型将 18 个补液通道全置为缺失，六个锚点均未知，在训练预处理、摘要与推理前执行。计算占位为 0，所有 anchor-known 标记均为 false，不代表临床实际为零。
- 所有中位数、分位数切点与缩放只用各折训练患者。基线常数也是训练患者等权中位数，未用全队列标签。
- 树模型预算固定 200 轮；神经模型沿用 NM-v1 的 60 轮、三种子。原残差头的 15 次拟合均塌为零，诊断后登记绝对量输出修订，再完成 15 次修正拟合；没有按外折成绩选超参数或提前停止。25 个折级树/常数估计器（120 个树回归头）和 30 次神经拟合均保留。
- 六项针对性测试通过。干预整个历史补液块、缺失模式和锚点后，已训练的无补液估计器在 9 个独立请求上的数值预测完全不变。55 个训练/评估范围均患者不交叉。
- 既有完整输入神经模型作为参考，其点输出只按数值做种子平均，不使用曾发现有错误的类别编号平均；所有动作附属指标都从同一绝对设置点预测计算。

生理状态可能反映过去治疗的影响，本实验排除的是补液记录字段，不是消除过去治疗的一切生理效应。

修正后的无补液历史神经模型输入量/设置 MAE 分别为 55.615/70.959。修正改了输出参数化，因此其与原完整输入残差神经模型的差距仅作参考，不能全部归为输入家族效应；匹配的完整/无历史树模型比较没有这个混杂。没有以外折挑选一个赢家再称为预先选定。

### 去锚点后暴露的神经实现问题

原模型使用 clamp(锚点+残差,0)。锚点全部未知并占位为 0 后，一旦残差变负，正目标也无法提供恢复该输出的梯度，15 次拟合均产生全零数值输出。实际前向/损失接缝上的测试已重现该现象。

修正模型改为 50×softplus(无量纲输出)，保持非负且负 logit 仍有梯度。50 来自原损失的既定单位尺度；没有根据外折分数挑选。编码器、允许输入、损失权重、训练轮数、折与种子不变。原始失败结果完整保留，修订见 absolute_amendment.json。此模型的平滑正值输出一般不产生精确零，所以数值 >0 的活动 F1 不能作为其独立活动识别能力的证据。

## 5. 结果应如何解释

1. 不含过去补液字段仍能学习到部分记录中下一小时输入量/设置的粗略规律，不能说该数据完全不可学。树模型相对训练常数、静态/时间对照的患者配对区间均支持误差下降。
2. 该信号至少部分来自静态严重度、伤后时间和观察记录模式，不能都归为生理数值。匹配树模型对照尚未建立数值本身的独立增益。
3. 本轮无补液历史方法尚未达到已有完整模型的精度；这不证明任何未来方法都无法达到。历史状态效应优先看匹配的树模型比较。
4. 绝对速度预测可以事后相对上一文书参考计算变化，但无补液历史模型推理时不知道上一设置，不能把该附属分数称为已经知道“该上调或下调多少”。常数预测也能因不同于上一设置而产生很多假变化，故不以此证明可学。
5. 这些是已多轮查看开发队列上的探索性证据，不是全新外部验证、在线可用性或临床获益证据。

## 6. 生理数据覆盖及参考性质

本轮十个时序生理字段中，当前 CVP 特征完全缺失；过去 24 小时内有血糖观测的原点比例约 15.66%，脉搏 7.64%。心率、呼吸、血氧和记录尿量覆盖较高。这里描述模型特征覆盖，不证明原始 449 人记录没有相关信息。

另对前一轮抽样的 45 人原始文件做了 CVP/中心静脉压字段名筛查，未发现其数值字段记录；未覆盖全队列，也未排除自由文本记录。详见 physiology_coverage.csv 与 raw_cvp_screen.json。

输入量仍含术中区间分配、完成事件反推等参考不确定性；本轮保留原标签以确保可比，没有按模型误差挑选或重写标签。前一轮发现的补液适配范围错误不会通过已屏蔽的补液字段进入无历史组，但完整输入参考仍保留旧版本，后续应另行版本化修复。

```powershell
python docs/experiments/no-fluid-history-20261015/verify_evidence.py
```
