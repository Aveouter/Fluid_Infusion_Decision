## 1. 口径与模型

- 标签：原六列协议；速率列权威，`bit = 1 ⇔ rate > 0`，不跨零流回填（`docs/label_protocol.md`）。
- 输入：仅预测起点之前可见的原始记录；24 小时历史；训练折内拟合缩放与缺失填补。
- 终点：下一小时设备设置速率；动作由同一最终速率相对共同前一小时参考设置生成。
- 主模型：双分支。速率分支输出绝对速率与活动概率；动作分支输出事件概率与四类方向；最终输出用速率分支的幅值、动作分支的方向/停止和活动门控解码。事件阈值与活动阈值均为原生 0.5。
- 对照：绝对速率分支（同骨干，无事件/动作头）；持续性、因果移动平均、恒 0、训练集中位数。
- 验证：291 名开发患者 5 折患者不交叉 OOF；3 个固定种子；72 名历史留出患者只评价一次。留出集历史上已被查看，不称外部或全新时间验证。

双分支不是两个模型拼接：速率分支和动作分支在同一前向中产生一个最终速率；动作分支只决定相对前一小时的侧向或停止，幅值始终来自速率分支。活动门控把低于 0.5 的活动概率置为精确 0。

**对 P1 的直接影响**：V7.1 的 0–24 h 总量 MAE 已为 2,412.6/2,298.8 mL（开发/留出；相对 41.6%/46.8%），0–48 h 为 4,485.5/3,824.4，0–72 h 为 5,630.9/5,070.3；持续性分别为 348.2/253.9、214.1/160.8、149.1/132.8。P1 不是只在 72 h 才失败，而是从第一个 24 h 就存在系统性负偏置，随后累积。逐小时 MAE 更好（V7.1 54.63/50.17 vs 持续性 60.00/56.20）与累计更差并不矛盾：lag−1 持续性的累计误差退化为区间两端点之差，V7.1 的逐小时偏差不会相消。


本报告同时给出两个 hold 候选：**hold=绝对速率**（动作优先，§2–3 为消融）与 **hold=上一小时 + 普通事件 BCE**（V7.1，总体误差优先，主结果见 §3.1）。前者在真实变化小时更准，后者在总体 MAE 与动作 F1 之间更平衡；两者与持续性的配对区间分别报告，不拼接。

**P1 改进尝试**：mean-matching 0.5 把 72h 总量 MAE 从 5,630.9/5,070.3 降到 4130.5/3930.5 mL，但设置 MAE 从 54.63/50.17 升到 57.78/53.13；P1 仍高于原模型 2,699.7 与持续性 164.1，不是无代价改进。见 §3.2。

## 6. 判定

开发 OOF 上设置 MAE 与持续性的差异未确认（配对区间跨零），不能写成总体优于持续性。
本节指 §2–3 的 hold=绝对速率消融；V7.1（hold=上一小时）的折 1–4 与历史留出总体 MAE 配对区间均排除零（§3.1），总体 MAE 改善在 V7.1 上成立。
P1 累计总量未通过：V7.1 的 72h 总量 MAE 5,630.9/5,070.3 mL、偏置 −5,630.9/−5,070.3；分液体平均约 1,975/1,731，不是总量。区间分解显示 0–24 h 已有 2,412.6/2,298.8 mL（相对 41.6%/46.8%）的误差，P1 不是 72 h 末端才出现，而是从第一天起的系统性低估累积。
72 h 合格集为 336/363；被排除的 27 人全层烧伤更多，72 h 累计结论只对完整随访者成立，不能无条件外推到全队列。
0–72 h 的核心体征复合缺失中位 42.5%，≤10% 层 0 人；低缺失层的绝对 MAE/P1 更高，但真实输注量高约 2–3 倍，相对 MAE 反而更低。高缺失四分位的相对 MAE 约 46–49%，提示缺失与相对误差同向，但分层是描述性的。
生理增量：0–24 h 开发折有 +0.0186 [+0.0083, +0.0292] 的严格动作 F1 信号，未达预设 +0.02，且未持续到 0–48/0–72 或历史留出；不能写成持续生理增量。
无论总体 MAE 是否跨零，主模型在真实变化小时上的 MAE 均明显低于持续性；严格动作 F1、停止召回与真实零流精确率同时报告，不把总体 MAE 或事件 F1 单独当作动作正确性。绝对速率对照在同骨干下去掉事件/动作头，用于判断动作端点是否以总体误差为代价。

本报告不宣称外部泛化、临床有效或治疗最优；历史留出已被查看，累计终点为条件一步之和，设置速率是文书记载的操作代理而非泵遥测。
