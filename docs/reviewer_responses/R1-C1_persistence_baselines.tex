\paragraph{Scope.}
This file addresses one reviewer concern only: whether the model's apparent
predictive performance could be explained by carrying forward the preceding
hour's infusion rate. It is a draft response, not the complete Response Letter.
The concern is paraphrased rather than reproduced verbatim.

\paragraph{Response.}
We agree that comparison with simple temporal baselines is necessary. The
evaluation includes last-value persistence and a causal moving-average
baseline, and compares them with the model using paired patient-level
uncertainty estimates. We have also limited the manuscript's claims to the
results supported by these comparisons.

The currently recorded patient-level results do not establish a consistent
MAE advantage for the model. The difference in MAE (model minus baseline) was
$+13.84$ against persistence (95\% CI $[-6.05,\;32.02]$) and $-1.44$ against
the moving average (95\% CI $[-11.88,\;10.80]$); both intervals include zero.
For patient-level macro-F1, persistence was higher: the difference (model minus
persistence) was $-0.0281$ (95\% CI $[-0.0428,\;-0.0147]$). We therefore do
not claim that the model consistently outperforms persistence or the moving
average.
