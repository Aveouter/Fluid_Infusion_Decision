\paragraph{Scope.}
This file addresses one reviewer concern only: whether the model's apparent
predictive performance could be explained by carrying forward the preceding
hour's infusion rate. It is a draft response, not the complete Response Letter.
The concern is paraphrased rather than reproduced verbatim.

\paragraph{Response.}
We agree that comparison with simple temporal baselines is necessary. The
repository's evaluation record documents last-value persistence and a causal
moving-average baseline, together with paired patient-level uncertainty
estimates. The claim-evidence matrix reports no consistent MAE superiority
over these baselines.

The currently documented patient-level results report the difference in MAE
(model minus baseline) as $+13.84$ against persistence (95\% CI
$[-6.05,\;32.02]$) and $-1.44$ against the moving average (95\% CI
$[-11.88,\;10.80]$); both intervals include zero. For patient-level macro-F1,
persistence was higher: the difference (model minus persistence) was $-0.0281$
(95\% CI $[-0.0428,\;-0.0147]$). These values and their definitions must be
verified against the final analysis output before submission.
